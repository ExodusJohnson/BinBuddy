\# BinBuddy



A Raspberry Pi Pico W + Pimoroni Pico Inky Pack smart home dashboard.



\## Features



\- eInk display

\- A/B/C buttons

\- Bin collection reminders

\- Weather information

\- WiFi updates



\## Hardware



\- Raspberry Pi Pico W

\- Pimoroni Pico Inky Pack



\## Planned Features



\- Next bin collection display

\- Weather forecast

\- Automatic updates

\- Customisable screens
